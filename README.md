# 💅 Ola Nailed It

Website for **Ola Nailed It** — Toronto nail technician Mariam's personal brand site.

## 🌐 Live Site

Hosted on GitHub Pages: `https://YOUR_USERNAME.github.io/ola-nailed-it`

## 📁 Files

- `index.html` — the full website (single file, no dependencies)

## 🚀 Deploy on GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set Source to **Deploy from a branch → main**
4. Your site will be live in ~60 seconds

## ✏️ Customise

- **Prices** — search for `From $` in `index.html` to update service prices
- **Instagram handle** — replace `@olanailiedit` with Mariam's real handle
- **Gallery** — swap the emoji placeholders with `<img>` tags of real nail photos
- **Booking** — replace the form with a Calendly embed or Google Form link for real bookings
